# 2026-09-15 地点流程与逐接口业务审查

## 结果

本地接通登录 → 地点范围 → 明确选择实际餐厅 → 上传 → Serving 入库 → 榜单。官网 66 个 Versailles 餐饮点使用稳定 ID，迁移 0016 保留历史两家及其投稿，不推断历史 RU/Cafétéria 归属。附近范围以直线距离 ≤1000 m 计算并排序；无坐标或异常坐标不参与定位，但可以搜索。餐厅选项移除 emoji。

未选地点时显示明确引导；点击今日开庭/长期榜单停留原页提示，不启动导航。已选地点可以重新切换，变更后清空上传餐厅选择，保留照片及菜名。偏好保存为本浏览器的餐厅 ID（30 天），不保存 GPS；URL 显式范围优先。附近范围是确认时的结果，不是后台持续追踪，换位置后需重新定位。

## 接口清单（全部 16 个路由）

| 接口 | 业务审查与验证 |
|---|---|
| POST /api/auth/email/request | 同源、邮箱格式、2 KiB JSON、邮箱/IP 限流、发送失败回滚；本地验证码、并发请求限制通过 |
| POST /api/auth/email/verify | 有效期、最多五次、重放/并发保护、哈希会话；null/数组/字符串请求体现在返回400 |
| POST /api/auth/logout | 同源、撤销会话、清 Cookie；退出后管理员接口401 |
| POST /api/uploads | 登录、同源、实际正文17 MiB上限、图片验证、日期、等级、活动餐厅ID、重复图、原子额度、D1事务、R2失败补偿；官网新餐厅完整投稿通过 |
| POST /api/ai/identify | 登录、同源、实际正文9 MiB上限、图片检查、每日额度、严格Schema、受限重试/缓存；无配置503，模拟模型回归通过 |
| GET /api/rankings | 类别/地点验证、未知地点400、空范围空数组；按所选地点最近行踪展示，社区评分不按地点拆分 |
| GET /api/dishes/:id | 仅活动且有可见行踪的未合并菜品；缺失/隐藏后404；详情仍展示全站行踪 |

| POST /api/dishes/:id/names | 登录、同源、名称/依据/限流、去重；补齐活动菜品可见性验证；正常提名与隐藏拒绝通过 |
| POST /api/dishes/:id/names/:suggestionId/endorse | 登录、同源、候选归属、禁止自赞/重复、额度、三人社区阈值；补齐菜品可见性验证 |
| POST /api/reports | 登录、同源、原因枚举、餐次/菜品目标匹配、存在性、额度；正常举报与限流通过 |
| GET /api/admin/queue | 管理员白名单；匿名401、普通用户403、管理员200；队列涵盖举报/补名/合并/补票 |
| POST /api/admin/actions | 同源+管理员权限；审核命名语言、隐藏、举报处理、AI建议采纳/拒绝、合并拆分及补票；既有并发/审计/原票归属回归通过 |
| POST /api/dishes/:id/vote | 登录、同源、活动可见菜品、等级、30/min、每人一道菜一票；重复409返回原判，合并后旧目标拒绝 |

地点范围是展示偏好，不是访问控制。投稿接口仍独立验证用户与活动餐厅，不信任 Cookie、URL 或前端下拉框。DeepL Key 只在服务器；机译不覆盖原文或正式名，英文输入翻译失败不阻断投稿。

## 本轮额外修复

- JSON 顶层类型校验，避免 null 被误报500。
- 隐藏餐次不再出现在菜品候选或公众补名接口；照片改为no-store。
- 两个R2对象写入全部结束后才决定回滚，部分失败清理对象；D1已提交后回执读取失败不再删除照片。故障注入测试覆盖R2失败、D1失败与回执失败。
- multipart 先按实际字节有界读取，再调用解析器；没有Content-Length或伪造小长度也不能绕过。上传17 MiB、AI9 MiB，超限取消读取并返回413。

## 限制和后续风险

- 本轮仅本地，未部署。生产是否拦截无长度头请求不能从本地结果推定；发布后须复验真实域名。
- 本地测试偶见workerd冷路由重启503/读超时；测试只对明确worker restarted响应或只读冷启动超时作有限重试，不重试未知结果的投稿写入；最终浏览器回归通过。
- 目录范围目前是Versailles的66个餐饮点，不代表全部法兰西岛。“自己输入”目前搜索已有官网目录，不创建未核实餐厅。
- 历史两家未区分RU/Cafétéria，仍在全站或原ID范围可查；选择具体新餐饮点不会擅自把历史投稿重新归类。
- GPS为浏览器提供，坐标为官网参考点；测试使用模拟定位，不代表每部设备实测精度。
- 逐接口审查不等于证明所有故障/并发组合不存在。已有榜单/详情全量查询仍有规模上限。候选多行同菜、旧管理动作审计未共事务已在后续发布审查中修复，见 release-review-20260915.md。
