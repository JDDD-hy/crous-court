# UI-20260910-01：页面、视觉与动效

状态：Confirmed for v1（2026-09-10）。

## 1. 视觉命题

“CROUS 塑料餐盘 × 游戏排行榜 × 中文互联网抽象审判现场”。

不做高级餐厅、不做米白生活方式杂志、不做默认 SaaS Dashboard。照片保持手机实拍质感，UI 像被反复盖章、涂改和重新排队的食堂公告墙。

## 2. 色彩与材质

- 托盘深蓝/灰：背景与结构；
- 番茄红：反对、下降、拉；
- 蛋黄黄：强调、候审；
- 洗碗液酸绿：赞同、上升、夯；
- 黑白高对比：正文与橡皮章。

五档等级 token 使用低饱和色，并同时显示文字与搞笑 emoji：

| 等级 | Emoji | 建议 token |
|---|---|---|
| 夯 | 🐮 | `#D88C86` |
| 顶级 | 👑 | `#D5B26F` |
| 人上人 | 😎 | `#D4CA78` |
| NPC | 🤖 | `#C4BDB3` |
| 拉爆了 | 💩 | `#B6AAA4` |

等级必须同时使用文字/图形，不只靠颜色。卡片可使用餐券锯齿、油渍纹理、歪斜拍立得与橡皮章，但正文保持清晰。

## 3. 页面结构

### `/` 首页

第一视口直接显示“今日被告”：大图、餐厅昵称/正式名、日期、当前判决、票数、`判得对`、`我有异议`。不得用大型 Hero 挡住投票。

下方依次：

1. 主食夯拉榜；
2. 小菜捡漏榜；
3. 最新神秘菜品；
4. 低干扰赞助区。

### `/upload` 上传

步骤：照片 → 餐厅 → 日期 → 标记 1 主食/最多 2 小菜 → 初判 → 疑似重复确认 → 发布。

餐厅选项显示：

- `🏠 All Suites 附近 — L’Expérimental`
- `🏫 Télécom 附近 — Escoffier`

菜名字段文案：`这是什么？知道就写，不知道交给群众。`

### `/dish/[id]` 菜品详情

大图、初判、当前社区判决、五档分布、移动历史、不同 Serving、名称状态和群众补名。

历次照片使用松散拍立得堆叠，但不得依赖滚动动画才能阅读。

### `/me/[id]` 我的内容

我的投稿、我的投票、待处理名称/重复确认。

### `/admin`

举报、未知菜名、疑似重复、隐藏内容；只对管理员开放。

## 4. 核心投票交互

默认显示：

- `判得对`：提交当前展示等级；
- `我有异议`：展开五档等级尺。

用户可以点击或拖动菜品卡到目标等级；拖动不是唯一方式，键盘和触屏点击必须可完成相同操作。

提交后先乐观更新视觉，失败时恢复并显示明确提示。

## 5. Codrops 动效映射

### MotionPath：跨等级移动

菜品从原档位沿弧线飞向目标档位：上升轻盈，下落带重量。时长 500–800ms，不旋转超过约 8°，落点必须稳定。

### GSAP Flip：榜单洗牌

投票、筛选或社区等级变化后，卡片平滑挤开并进入新位置。不得闪烁、瞬移或丢失焦点。

### Polaroid：历史照片

详情页照片轻微错位堆叠；展开后按日期排列。只借鉴视觉组织，不做长篇滚动展览。

### Pixel 效果

v1 使用 Canvas 2D pixel shatter：仅当菜品一次跨越至少 2 档向下移动，或首次进入“拉爆了”时播放。像素从卡片底部少量碎裂坠落，600–900ms，结束后销毁 Canvas。

不改变真实图片文件，不遮挡结果，不自动循环，不播放闪烁。

### Three.js / Rapier Pixel Voxel Drop

标记为 post-v1 彩蛋。仅桌面、空闲时延迟加载；移动端和 reduced-motion 完全禁用。未通过性能预算不得合入。

## 6. 动画强度

| 级别 | 场景 | 时长 |
|---|---|---:|
| 微反馈 | 按钮按压、盖章、hover | 120–220ms |
| 状态变化 | MotionPath、Flip | 500–800ms |
| 重大判决 | pixel shatter、升级庆祝 | 600–900ms |

启用 `prefers-reduced-motion: reduce` 时：移除路径、粒子、像素和视差，只保留 0–100ms 淡入或即时更新。

## 7. 关键文案

- 未知名称：`今日菜单无人取证，启动全民认菜。`
- 补名入口：`这盘到底是什么？`
- 赞助按钮：`🤖 给 AI 加个菜`
- 赞助正文：`你的一票决定菜品从夯到拉，你的一欧决定服务器从活着到寄。`
- 彩蛋：`赞助达到目标后，我们将启用 AI 识菜；再多一点，开发者今晚就不吃 CROUS 了。`
- 反转小字：`有了你们的帮助，我就不用再吃 CROUS 了——然后本网站也将因为失去一手信源而倒闭。`

## 8. 响应式与无障碍

- 移动端等级尺未来采用两行或垂直展示；完整移动端适配延期至全部既定阶段之后；
- 触控目标至少约 44px；
- 图片有基于菜名/临时描述的 alt；
- Dialog/Sheet 正确管理焦点；
- 动画后焦点不移动；
- 用户可在设置中关闭夸张动画。
