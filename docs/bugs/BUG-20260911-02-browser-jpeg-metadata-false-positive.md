# BUG-20260911-02：浏览器重编码 JPEG 被误判为隐私元数据

状态：Fixed（2026-09-11）。

## 症状

用户选择普通 JPG 或 PNG 后，浏览器已经重编码，服务端仍提示图片包含 EXIF 或注释元数据。

## 根因

JPEG 校验把 APP1–APP15 全部视为隐私元数据；Canvas 编码器可能合法写入 APP14 色彩标记，因此所有此类输出都会被误拒绝。

## 修复与验证

- 继续拒绝 APP1（EXIF/XMP）、APP13（Photoshop/IPTC）和 COM 注释段；
- 允许不含个人信息的编码与色彩标记，包括 APP14；
- 回归测试先复现 APP14 误拒绝，再验证普通编码图通过、EXIF 图仍被拒绝；
- 单元测试 13/13、lint、生产构建和认证上传链通过。
