# BUG-20260912-01：上线前资源限额加固

状态：Closed（2026-09-13）；两个上线阻塞均已修复并回归验证。

## 已确认问题

1. 公开验证码 JSON 接口在 2 KB 判断前完整读取请求体；并发超大正文可造成额外 Worker 内存与 CPU 消耗。严重性：Medium。
2. 投稿采用最近 Meal 数量的先查后写限额；同一已登录账号并发上传不同图片可绕过十分钟五次限制并增加 R2/D1 成本。严重性：Medium。

## 修复验收

- JSON 使用有上限的流式读取，并保留缺失/伪造 `Content-Length` 的服务端限制；
- 上传在任何 R2 写入前使用 D1 原子计数器预占次数；
- 增加超大流式正文和六路并发投稿回归测试；
- Phase 7 发布前重新执行安全检查。

## 修复结果

- 验证码 JSON 在读取流过程中累计字节，超过 2 KB 立即取消，缺失或伪造 `Content-Length` 不能绕过；
- 新增 `upload_rate_limits`，图片写入 R2 前以 D1 原子 UPSERT 预占十分钟窗口次数；
- 单元测试覆盖有限正文与超大流；真实本地 Worker 六路并发投稿结果为五次成功、一次拒绝；
- 完整安全复审仍作为 Phase 7 发布前独立验收项。
